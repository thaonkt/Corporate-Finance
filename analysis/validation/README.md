# analysis/validation/

Self-audit and validation reports produced during Stage 3 and Stage 4 of the project.

This folder stores human-in-the-loop (HIL) iteration notes, annotated diffs, and any verification write-ups that document how LLM-generated outputs were reviewed and corrected. Files should follow the project naming convention:

```
YYYY-MM-DD-{lastname}-{company-slug}-{stage}-{type}.md
```

**Examples:**
- `2026-06-19-nguyen-vinamilk-stage4-iteration.md` — HIL iteration note from Stage 4
- `2026-07-03-nguyen-vinamilk-stage5-verification.md` — Stage 5 output verification report

Each file should record what was checked, what was found, and what was changed — so the audit trail is complete and reproducible.
