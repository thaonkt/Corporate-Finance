# docs/specs/

Technical specifications produced at Stage 4 of the project.

A spec defines exactly what the analysis must do — precise enough that an LLM with no other context can execute it correctly. Files should follow the project naming convention:

```
YYYY-MM-DD-{lastname}-{company-slug}-spec.md
```

**Example:** `2026-06-18-nguyen-vinamilk-spec.md`

Each spec document includes the analytical objective, data sources, ratio definitions (in named-range notation), output format requirements, and any edge-case handling instructions.
