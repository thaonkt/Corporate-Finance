# docs/decisions/

Executive memos and decision documents produced during the project.

This folder holds all Stage 2 company-selection memos and any other decision memos written during the course. Files should follow the project naming convention:

```
YYYY-MM-DD-{lastname}-{company-slug}-selection.md
```

**Example:** `2026-05-21-nguyen-vinamilk-selection.md`

Each memo documents the reasoning behind a key project decision — company choice, methodology, or analytical approach — so reviewers can trace how conclusions were reached.
