# Corporate Finance — BUS 629 Portfolio

Portfolio repository for **BUS 629 VEMBA — International Corporate Finance** at the University of Hawaiʻi at Mānoa, Shidler College of Business.

Maintained by **Nguyen Khong Thanh Thao** — Marketing Manager, Commercial Segment at Lenovo Vietnam, with 10+ years of experience across technology, B2B marketing, and commercial strategy. See [BIO.md](./BIO.md) for full profile and [RESUME.md](./RESUME.md) for complete work history.

## Repository Structure

| Folder | Purpose |
|---|---|
| `docs/` | Assignment specs, project plans, decision notes, and reusable templates |
| `models/` | Financial models — organized into `templates/` (starter shells) and `builds/` (assignment work) |
| `data/` | Raw, unmodified source data files (CSV, Excel, filings) |
| `analysis/` | Validation reports, sensitivity analyses, and supporting write-ups |
| `deliverables/` | Final, submission-ready outputs for each course stage |
| `GitHub-BUS629/` | Reference materials and resources related to the BUS 629 GitHub workflow |
